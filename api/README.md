# Служба игры вдвоём

`duel.js` — пересыльщик. **К самой игре не подключается и на страницу не
попадает**: Vercel запускает файлы из этой папки как службу, а не отдаёт их
браузеру.

Он не знает про игру ничего — получает от одного непрозрачную строку и отдаёт
второму, кто зашёл в ту же комнату. Правила считают сами игроки у себя.
Поэтому заменить его на что угодно другое стоит одной строчки в игре.

Зависимостей нет ни одной: ни `package.json`, ни установки, ни сборки.

## Что нужно, чтобы он работал

В проекте Vercel должно быть подключено хранилище Redis. Ключи служба берёт из
настроек, которые Vercel подставляет сам, — вписывать их никуда не надо.

Если хранилище не подключено, служба честно отвечает
`хранилище не подключено к проекту`, а не падает молча.

## Проверить, что живая

```bash
curl -X POST https://tricky-dungeon.vercel.app/api/duel \
  -H "Content-Type: application/json" -d "{\"что\":\"создать\"}"
```

Должна вернуть код комнаты и зерно.
