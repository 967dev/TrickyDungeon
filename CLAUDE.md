# TrickyDungeon

Карточная игра. Целевая платформа — **Telegram Mini App**, хостинг статикой на
GitHub Pages или Vercel.

**Направление зафиксировано: развиваем `gametest`.** Его `index.html` лежит в
корне, импортирован дословно отдельным коммитом (`c36ea76`, из upstream
`7f57ad8`) — так любая правка видна диффом относительно оригинала, и всегда
можно сравниться с исходником.

---

## Формат

**`index.html` (разметка и SVG) + `css/` (11 файлов) + `js/` (14 файлов).**
Обычные теги, **не модули**: файлы делят одни глобали и выполняются подряд.

Порядок подключения значим — и в стилях, и в скрипте:

- **CSS**: каскад решает порядок. Порядок слоёв объявлен один раз, `@layer` в
  `css/01-base.css`; каждый файл заворачивает своё тело в свой слой.
- **JS**: всплытие функций работает внутри файла, но **не между файлами**.
  Значит код, выполняющийся ПРИ ЗАГРУЗКЕ, не может звать функцию из файла
  ниже. Запуск (`14-boot.js`) поэтому идёт последним.

Правило для стилей: **новое правило кладётся рядом с тем, что оно красит**, в
файл своей темы. Класс ошибок, который это закрывает: правило, положенное
далеко от родственного, проигрывало ему по порядку.

Почему без сборки: GitHub Pages, Vercel и `devserver.py` отдают это как есть,
без конфигов. ES-модули отложены сознательно — они меняют семантику (глобалей
не станет) и ломают инструменты, которые водят игру через те же глобали.

Две ловушки, обе молчаливые:

- пути в `url()` внутри CSS считаются ОТ ФАЙЛА СТИЛЕЙ, а не от страницы:
  после выноса они стали `../art/`;
- двойным кликом (`file://`) игра больше **не открывается** — внешние скрипты
  так работают, но проверять надо через `devserver.py` (он же запрещает кэш).

### Правила боя отдельно от подачи

**`js/10-rules.js` не имеет права трогать DOM.** Правила считают состояние и
складывают в `B.ev` события — что произошло. `js/11-battle.js` их проигрывает:
анимация, звук, строка журнала. Слова для игрока — тоже подача (`effText`),
правила отдают только «что и на сколько».

Зачем: пока это было одним кодом, `dealDamage` ждал анимацию смерти, а `aiTurn`
вперемешку решал и показывал. Отсюда шли три беды, и все три случились —
баланс приходилось мерить ПЕРЕПИСАННОЙ моделью (см. `BACKLOG.md`), одно правило
жило в двух местах и разошлось (у врага не было ветки `mana`, а `healAll` не
лечил ему героя), и проверить правило можно было только глазами.

Что это дало: `simulate()` гоняет **12 000 настоящих боёв за 0,45 секунды**, а
темп показа стал ручкой (`ТЕМП`), не свойством боя.

Подача при этом обязана помнить: состояние уже конечное, а рассказ только
начался. Перед отрисовкой числа отматываются на непоказанные события —
`откат()`. Без этого здоровье падает сразу на весь ход врага, а погибшие
исчезают раньше, чем по ним ударили.

### Чем проверять

- `tools/_tests.js` — 860 проверок, 15 групп, включая одиннадцать боёв
  автоигроком и сверку КАЖДОГО обещания карты с настоящими правилами, за обе
  стороны (группа 15). Отчёт печатает `групп: 15/15`: исключение обрывает
  прогон целиком, и без этой строки обрыв читался как успех. Гонять в браузере:
  `fetch('tools/_tests.js').then(r=>r.text()).then(t=>(0,eval)(t))`, затем
  `await __тесты()`. Бои идут на `ТЕМП=0`: спрятанная вкладка душит таймеры до
  одного в минуту, и на паузах подачи прогон вставал.
- `tools/_snap.js` — снимок вёрстки: 47 вычисленных свойств и прямоугольник у
  каждого элемента на десяти экранах. Порог доверия: ноль расхождений.

## Референс

**github.com/967dev/gametest** («БАМ-БАМ: КАСКАД») — планка качества, репозиторий
пользователя. Один `index.html`, **ноль внешних ассетов** (проверено:
`git ls-files` → только index.html; ни png, ни data-URI, ни веб-шрифтов).

Его визуальный язык:

- палитра: `--yel #ffd52e`, `--mag #ff4fd8`, `--cyn #35f0ff`, `--red #ff3355`,
  `--grn #3dff8a`, фон `#0a0a0f`
- шрифты: `Arial Black/Impact` для дисплейного, моно для служебного
- **плоские комикс-тени** `Npx Npx 0 rgba(...)` — без блюра. Кнопки «вжимаются»:
  hover `translate(-2px,-2px)` + тень больше, active `translate(2px,2px)` + тень в 0
- диагональные полосы `repeating-linear-gradient(-45deg, ...)` с бегущим
  `background-position`
- тиры карт `t0..t4` + секретный, автономная голография на CSS
  (`mix-blend-mode: color-dodge` + радужный градиент, анимируется всегда)
- процедурный WebAudio, без аудиофайлов
- кривая сложности по трём осям: HP врага, тир его карт, «мастерство» ИИ
  (`skill = 0.15 + этап*0.09` — ранние враги мешкают и играют случайно)

**Главный урок прошлого захода:** не патчить чужой прототип, натягивая на него
внешность референса. Так получилось «ни то ни другое». Старый прототип
«Elemental Chaos» отодвинут в `../cards_old/`.

## Telegram Mini App

| Требование | Почему |
|---|---|
| `Telegram.WebApp.disableVerticalSwipes()` | **Критично.** Свайп-вниз-закрыть в Telegram дерётся с драгами (срыв этикетки пака, перетаскивание карт). Без этого механика ломается |
| `viewportStableHeight` вместо `100vh` | В webview `100vh` врёт, вёрстка съезжает |
| **Мобильный дизайн первым** | TMA — это телефон. Всё должно работать на ~375px пальцем: размеры карт, веер руки, зоны попадания |
| `CloudStorage` для сейвов | Родное хранилище TMA, синхронится между устройствами. `localStorage` в webview может вычищаться → делать с фолбэком |
| `HapticFeedback` | Бесплатная «сочность»: срыв пака, переворот карты, удар |
| Деградация без Telegram | `telegram-web-app.js` — единственная внешняя зависимость. Без неё файл должен открываться локально как обычный HTML |

Тему Telegram **игнорировать** — у игры свой арт-дирекшн, подстройка под
светлую/тёмную тему клиента его только испортит.

## Арт

**Никаких платных API.** У пользователя локальный **ComfyUI + SDXL** — генерация
бесплатна. Но сначала проверять, нужен ли растр вообще: референс выглядит дорого
на чистом inline-SVG + CSS.

Если генерируем: **512×768** на карту (на экране карта ~140×200px, 4K бессмысленен).
Главный риск — не качество, а **консистентность**: 40 карт без единого
стиль-промпта/seed-дисциплины дают солянку, которая выглядит хуже ровного
line-art. См. скилл `create-game-assets` (производить семьями от одного
утверждённого эталона).

`save-systems` · `procedural-gen` · `create-game-assets`

Особенно к делу: в `card-game` описана ошибка «одна функция на карту вместо
эффектов-как-данных» — именно из-за неё в старом прототипе `deathrattle`,
`shortCircuit` и `endTurn` были объявлены в базе карт, но не работали.

## Работа с репозиторием

Git есть, и это важно: правки должны быть обратимыми (`git checkout .`), а не
односторонними. Коммитить осмысленными шагами.

Проверять в браузере, а не на словах: открыть игру, кликать реально, смотреть
консоль. В прошлый раз баг «карты не переворачиваются» нашёлся только живым
кликом — синтетические вызовы его скрывали.
